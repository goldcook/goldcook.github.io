# Goldcook 个人主页一期记录

## 1. 一期定位

这个网站不是技术简历，也不是项目作品集，而是一份持续更新的个人主页。

一期采用温暖的 16-bit 像素 RPG 风格，把主页组织成一个可以探索的小世界：访客从开场进入世界地图，再选择不同地点了解 Goldcook 当下的工作、学习、生活和思考。网站保留成长记录与未来内容扩展能力，但不会为了填满页面而公开不成熟或过于私人的内容。

一期的核心表达是：

- 刚从学生阶段走进职场，在互联网从事算法相关工作。
- 保持学习，关注 AI 与强化学习，也学习怎样工作和生活。
- 工作不是全部，生活里还有音乐、小说短剧、联机游戏和看云。
- 正在理解成年人的身份、关系、责任与更长远的生活方式。
- 网站会继续生长，但不承诺固定更新频率。

## 2. 当前信息架构

### 开场

开场负责最短的自我介绍、人生进度氛围和玩家状态。它只保留一个主要行动：进入世界地图。

首页已经预留 `socialLinks` 数据入口。当前数组为空，因此社交媒体链接不会显示。以后确认需要公开的平台后，可以直接补充数据，不需要重新设计首页结构。

### 世界地图

世界地图是主页的主目录，当前包含六个并列区域：

| 区域 | 作用 |
| --- | --- |
| 工作城镇 | 当前工作状态、职场 Landing 与算法工作概览 |
| 学习营地 | 学会工作、学习前沿、学会生活 |
| 生活村落 | 音乐、小说短剧、联机游戏、看云 |
| 思考高塔 | 工作边界、新责任和想要怎样生活 |
| 杂谈书屋 | 未来收拢短文、小想法或外部原文链接 |
| 来信驿站 | 通过 Gmail 联系 |

地图区域与道路由 `content.js` 中的 `mapAreas` 自动生成。新增区域时仍需为新场景补充 HTML 和 CSS，但不需要手工绘制 SVG 道路或修改区域计数。

### Background

`BACKGROUND / 背景故事` 是地图边框上的特殊入口，不与六个普通地图区域并列。

公开页面只展示四个阶段的简短概览：儿时、中学、大学、进入职场。时间树节点、章节数量和树枝连线由 `lifeStages` 数据生成，可以继续增加阶段。

详细经历属于私人档案，不进入公开构建。本机使用 `localhost` 或 `127.0.0.1` 预览时，页面会尝试加载 `private/timeline.local.js`；正式域名不会加载该文件。

### 杂谈书屋

一期只保留一个有设计感的空状态：

- 标题：偶尔写点东西
- 空状态：这里暂时还没有

这里不是需要定期维护的独立博客。以后可以采用三种方式更新：

1. 在主页里放标题与短摘要。
2. 搬运一段愿意公开的完整文字，并链接到独立站内页面。
3. 只保留标题、摘要和其他社交平台的原文链接。

`notes` 条目支持无链接卡片，也支持站内相对链接和 HTTP(S) 外链。外链会在新标签页打开。

## 3. 视觉与交互原则

- 保持温暖、轻松的像素游戏世界，而不是后台面板或技术简历。
- 主要颜色是天空蓝、草地绿、奶油色、夕阳橙和深海军蓝。
- 像素感来自硬边框、块状阴影、地图语言和阶梯动画，不以牺牲可读性为代价。
- 桌面端的主要场景尽量严格控制在一屏内，不要求上下滚动。
- 手机端允许自然纵向滚动，优先保证字号、点击区域和内容完整性。
- 页面导航遵循“开场 → 地图 → 场景 → 返回地图”的游戏循环。
- 悬浮音乐播放器在所有场景都可以使用，手机端默认折叠成右下角按钮。
- 减少无必要的解释文案。界面本身能够表达含义时，不重复说明。

完整设计约束见根目录的 `DESIGN.md`。

## 4. 代码结构

| 文件 | 职责 |
| --- | --- |
| `index.html` | 所有场景的语义结构、固定文案、SEO 和资源版本号 |
| `content.js` | 地图、成长阶段、学习、生活、思考、杂谈、社交入口和音乐数据 |
| `script.js` | 场景路由、地图与时间树生成、私人档案加载、音乐播放器和动态内容渲染 |
| `styles.css` | 像素视觉、地图地形、桌面单屏布局和手机响应式布局 |
| `scripts/update-qq-playlist.mjs` | 从公开 QQ 音乐歌单读取前三首并更新 `content.js` |
| `.github/workflows/sync-qq-music.yml` | 每周运行歌单同步，也支持手动触发 |
| `private/` | 私人时间线与整理材料，只存在于本机和私有备份 |

网站没有框架和构建步骤，使用原生 HTML、CSS 和 JavaScript，可以直接由 GitHub Pages 托管。

## 5. 可扩展数据

### 新增地图区域

在 `content.js` 的 `mapAreas` 添加：

```js
{ name: "区域名称", icon: "图标", x: 50, y: 50, target: "screen-id" }
```

然后在 `index.html` 增加对应的 `data-screen="screen-id"` 场景，并在 `styles.css` 中设计场景和地图地形。道路和区域计数会自动生成。

继续增加区域前必须重新检查手机点击热区。当前六个地点加旅程起点在 `390×844` 下没有重叠，但地图下半区已经比较密集。

### 新增成长阶段

在 `lifeStages` 添加包含 `code`、`title`、`summary`、`tags`、`x`、`y`、`accent` 和可选 `privateId` 的对象。树干、分支、节点序号和章节计数会自动更新。

公开 `summary` 应保持概览性质，不包含城市、学校、公司、具体住址或能够组合定位个人的信息。

### 新增杂谈

在 `notes` 添加：

```js
{
  tag: "随想",
  title: "标题",
  excerpt: "两三句公开摘要",
  url: "https://example.com/or/local-page"
}
```

`url` 可以省略。省略后会显示为站内普通卡片；填写 HTTP(S) 地址时会显示为外链。当前实现会拒绝 `javascript:`、`data:` 等不安全协议。

如果要放完整长文，建议新建独立页面或内容目录，再从杂谈书屋链接过去，避免把主场景变成长滚动列表。

### 新增社交入口

在 `socialLinks` 添加：

```js
{ label: "平台名称", url: "https://example.com/profile" }
```

只公开已经确认愿意长期展示的平台。数组为空时，首页不会留下空白区域或占位按钮。

## 6. 音乐方案

悬浮播放器有两部分：

- 三段通过 Web Audio API 实时生成的原创像素 BGM。
- 三个“最近在听”的 QQ 音乐官方歌曲页面入口。

原创 BGM 只使用宽泛的流行、轻松和游戏音乐气质，不复制或改编可识别的受版权保护旋律。主页不抓取、不代理、不托管 QQ 音乐音频。

QQ 音乐同步流程：

1. GitHub Actions 每周一运行同步任务。
2. 工作流从仓库 Secret `QQ_PLAYLIST_ID` 读取歌单编号。
3. 脚本读取公开歌单前三首，更新 `content.js` 标记区间。
4. 只有歌曲发生变化时，GitHub Actions 才会自动提交。

歌单编号、QQ 账号信息和浏览器登录状态都不应写入公开代码。

## 7. 隐私边界

公开站点可以展示：

- Goldcook 这个名字。
- Gmail 联系邮箱。
- 互联网算法工作的概括。
- AI、强化学习、工作、学习、生活和兴趣方向。
- 经过人工确认的成长阶段概览与杂谈。

公开站点不展示：

- 公司、团队、学校和具体城市。
- 旧居、精确成长地点或能够组合定位的信息。
- 私人日记、照片、社交动态和详细个人经历。
- 未经确认的家人、朋友、伴侣相关信息。
- QQ 歌单编号和其他账户标识。

私人内容只保存在私有备份仓库的 `private/` 中。公开仓库通过 `.gitignore` 忽略整个 `private/` 目录。发布前必须运行 `git ls-files 'private/**'`，确认输出为空。

## 8. 本地预览与公开模式

启动本地服务器：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

两个预览地址用途不同：

- `http://127.0.0.1:4173/`：本机所有者模式，可以加载 `private/timeline.local.js`。
- `http://goldcook.localhost:4173/`：公开访客模式，不加载私人档案，适合发布前检查。

不要直接双击 `index.html` 预览，因为文件协议不能准确模拟路由、脚本和私人档案边界。

每次正式发布前至少执行：

```bash
node --check content.js
node --check script.js
node --check scripts/update-qq-playlist.mjs
git diff --check
git ls-files 'private/**'
```

浏览器需要检查：

- 桌面 `1466×871`：首页、地图和各主要场景保持单屏，无页面级溢出。
- 手机 `390×844`：无横向滚动，地图节点可点击且点击热区不重叠。
- `goldcook.localhost`：不加载私人脚本，不出现私人档案正文。
- 悬浮播放器：展开、播放、暂停、切歌和音量控制正常。
- 地图循环：每个地点都能进入并返回地图，浏览器前进后退正常。

## 10. 发布与备份

公开仓库的 `main` 分支由 GitHub Pages 直接发布到 <https://goldcook.github.io/>。

正式发布流程：

1. 完成本地语法、隐私和响应式检查。
2. 使用 `goldcook <goldcook4@gmail.com>` 作为提交身份。
3. 提交并推送公开仓库 `main`。
4. 等待 GitHub Pages 更新，并确认线上 HTML 使用最新资源版本号。
5. 将相同站点文件同步到私有完整备份仓库。
6. 不要用公开 README 或 `.gitignore` 覆盖私有仓库的安全警告与私人文件跟踪规则。

私有备份仓库必须始终保持 Private，不能启用 GitHub Pages，也不能将其历史合并回公开仓库。
