# goldcook.github.io

Goldcook 的个人主页，一份以温暖 16-bit RPG 为视觉语言的人生游戏存档。

页面采用“开场 → 世界地图 → 独立场景”的结构，地图是内容目录，各场景可随时返回地图重新选择。世界地图还提供“背景故事”入口，用纵向时间线公开展示儿时、中学、大学与进入职场四个阶段的简短概览。个人经历详情不进入公开构建。

地图区域、道路和成长时间树都从 `content.js` 生成，可以继续增加新区域与人生阶段。“杂谈书屋”用于偶尔收拢散落在其他平台的文字、小想法或外部原文链接；当前保留为空书架。开场页也预留了社交主页入口，`socialLinks` 为空时不会显示。

本机预览会尝试读取 `private/timeline.local.js`，存在时可从带锁节点进入私人档案。该文件被 Git 忽略，不会发布到 GitHub Pages。

## 本地预览

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 <http://localhost:4173>。

## 更新内容

- `index.html`：页面结构、固定文案和 SEO 信息。
- `content.js`：地图区域、公开分享、社交入口、成长时间树、成长/生活/思考内容、原创 BGM 与 QQ 音乐入口。
- `styles.css`：像素游戏视觉、桌面单屏场景与移动端响应式布局。
- `script.js`：地图交互、菜单与可切换的悬浮 Web Audio BGM。

网站版本标记也集中在 `content.js` 的 `siteEdition` 中。它表示人工确认的主页版本，不随自动歌单同步变化；下次正式更新时只需要修改版本名称、展示日期和 ISO 日期。

新增公开内容时，只编辑 `content.js` 中的 `notes`。条目可以直接承载摘要，也可以通过 `url` 指向其他平台的原文。私人日记或未经确认的个人记录继续保存在被忽略的 `private/` 目录，不应自动同步到公开书屋。

## 音乐说明

三段“最近最爱 · 像素印象”均通过 Web Audio API 实时生成。它们只借鉴宽泛的音乐气质，不包含第三方音频文件或受版权保护的可识别旋律。

“最近在听”使用 QQ 音乐官方歌曲页面，不抓取或代理第三方音频。`.github/workflows/sync-qq-music.yml` 每周读取指定公开歌单的前三首并更新入口，也支持在 GitHub Actions 中手动触发。歌单编号保存在仓库 Secret `QQ_PLAYLIST_ID` 中，不进入公开代码。站内直接播控需要另行申请 QQ 音乐开发者平台能力。
